# Base firmware 1.0.1

This USB-managed base adds independent base/app version reporting to MQTT,
Firebase and application-ready logs. It includes the bench fixes for
CircuitPython bytearray slicing, explicit Google TLS roots, and string-valued
OTA enable settings. The reported base version identifies code.py, boot.py,
libraries and public certificates as a bundle, not the CircuitPython interpreter.

Install deliberately by USB in D9 maintenance mode. OTA updates still replace
only a verified application slot and cannot install this base. Preserve device
settings, credentials, NVM and confirmed app journals. Follow the recovery and
bench checklist in ../ota-operations.md; this change has host validation but
has not been installed or physically validated on the board yet.

Application API 1 and the existing 1.0.0 minimum-bootstrap contract are unchanged.
Older applications and releases remain compatible. Older boards that omit a
base version appear as “not reported” in Administration.
