# Base firmware 1.0.13

Reverse TFT Feather buttons now have distinct normal-operation actions. D0
(active LOW) or D1 (active HIGH) toggles a website QR view; it returns to status
after 20 seconds. The QR opens the canonical website without pairing arguments.
The local hold countdown remains visible. D2 (active HIGH) toggles a persistent,
one-shot next-reboot choice on the bottom TFT row: Normal or Wi-Fi setup. It
never restarts the board itself. The flag is consumed before entering setup;
subsequent reboots return to normal. D1 held at startup remains recovery.
All three buttons are debounced inputs and released on exit. XIAO outputs and
D9 OTA recovery are unchanged; Feather OTA remains disabled.

Administration's explicit Restart setup action preserves the trusted device
identity, allowed users, nickname, audit history and encrypted broker identity.
It disables new web commands transactionally, refuses active/pending commands,
and queues a unique reset generation. The board polls only while idle, drains
MQTT and checks its actual local lease again, saves a pending marker, closes
MQTT, and acknowledges the generation over verified TLS. Only after a matching
acknowledgment does it clear local Wi-Fi/MQTT settings and reload into setup.
Lost acknowledgments and failed local writes keep the marker and old Wi-Fi;
boot retries the ACK before reconnecting MQTT. New registration requires a
fresh authorized QR claim and the matching generation. Broker credentials are
reused for this retest flow; this is not a transfer or credential rotation.

Host validation covers button polarity/debounce, one-shot NVM behavior, website
QR contents/timeout/cached rendering, live countdown, reset persistence order,
ACK identity/generation checks, cleanup failure and boot retry without MQTT.
Backend/browser/emulator tests cover authorization, ownership preservation,
expired/stale claims, overlapping publishes, deduplication and polling races.
Native USB installation and passive observations are recorded below when run.
The production reset itself is left for an interactive onboarding test.

USB installed on Reverse TFT Feather 37cc02 (application 1.0.1, CircuitPython
10.3.2). All 113 host tests and pre-commit checks passed. Native checks verified
actual miniQR generation (37 modules including its quiet zone), cached website
view updates, a six-hour countdown, footer bounds, released-button polarity
and pure one-shot/debounce helpers. The board restarted and reconnected to
Wi-Fi/MQTT without changing NVM credentials. Evidence is in ignored local
`artifacts/restart-native-boot.log`. No hold command or reset-setup request was
issued. Full web checks passed: 46 unit tests, 83 browser tests (one existing
WebKit offline-launch skip) and 27 actual local emulator tests.
