# Base firmware 1.0.6

The phone showed truncated captive-portal markup despite the board generating
the complete HTML, including its Save button. Send HTML in paced 512-byte
chunks, use a five-second socket deadline, and allow queued TCP data to drain
before closing. Do not append a second HTTP response after a failed partial
send. Request diagnostics contain only stages, error types, whitelisted parser
reasons and counts; no request bodies, headers or credentials are logged.

Includes the previously installed persistent Save button and 1.0.5 QR layout.
Validation: host regression reconstructs a full response through a bounded
socket writer, including byte-accurate Content-Length and final Save markup.
USB install and interactive phone loading/saving are required to verify the
transport fix on actual hardware. Gate activation is not tested.
