The normal-operation website QR shortcut keeps the dark Drawbridge header and
device ID, with a centered QR below it. The view contains no hold countdown,
D2 reboot selector or button hint. D0/D1 toggle back to normal status, or the
20-second timeout returns there. D2 still selects the one-shot reboot mode;
the selected mode is visible when normal status returns. The normal Wi-Fi,
MQTT, hold countdown and reboot footer are unchanged. Secure onboarding QR
and registration progress remain separate.

The QR uses the canonical website root without pairing parameters. Its full
quiet zone stays inside the lower TFT area. The rendered group is cached, so
ongoing status/hold changes do not rebuild the QR. This changes the USB-managed
display and caller only; no hold, pin allocation or networking policy changes.

Host checks verify the dark header, text contents, centered lower QR bounds,
full website URL, group reuse and status return. Native USB installation and
passive verification results are recorded after execution. No gate command or
production Restart setup is needed for this UI change.
