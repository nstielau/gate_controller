# Base firmware 1.0.7

Selecting a saved/nearby SSID hides and disables the manual network-name field.
Selecting the default Choose a network option shows and enables it again,
retaining any typed name. Disabling the hidden input prevents its old value
from overriding the selected SSID when submitting the form. This is entirely
local and requires no external scripts or assets.

Validation: browser checks in Chromium and WebKit cover visibility, form-data
exclusion, and restoration of the typed name. Run host tests and precommit,
then USB install the portal and base identity. Interactive phone confirmation
is required; no gate command is sent during validation.
