# Base firmware 1.0.12

Normal Reverse TFT status shows the actual local hold lease's remaining time
as MM:SS or H:MM:SS. Positive fractions round up, so a running hold never reads
00:00. The countdown follows replacement, cancel and expiry, including while
Wi-Fi/MQTT are disconnected. Gate GPIO and indicator servicing still precede
display work. No command handling, hold duration or pin assignments change.

Idle footer: “D1 + RESET: Wi-Fi setup”. During a hold: “Reset ends hold”. The
footer fits the 240×135 TFT below the separate Wi-Fi, MQTT and Hold rows.
Status labels update in place when the displayed second or connectivity
changes; the background and static labels are not rebuilt every second.
Switching from another screen invalidates the cached status labels.

Validation covers time boundaries, local lease rounding/expiry/replacement,
offline countdown, display object reuse and footer switching. Run the full
host suite and pre-commit checks before intentional USB installation. Native
screen/timing and passive online checks must be recorded after installation;
no automatic gate command is required for these checks.

USB installed on Reverse TFT Feather 37cc02 (application 1.0.1, CircuitPython
10.3.2). All 101 host tests and pre-commit checks passed. Native rendering
verified minute/hour formatting, OFF/active footer switching, ten display
objects, reused group identity, and visible label bounds. Five active text
updates took approximately 0.5–16 ms; this is a small rendering probe, not a
hard real-time guarantee. No gate command or physical output was activated
by that screen-only probe.

The following 70-second passive run passed with seven online heartbeats and
16 alternating D9 edge samples at 125–149 ms. It observed an active hold with
steady control HIGH and then a return to LOW, without losing the Wi-Fi/MQTT
session or boot. The observer published no gate command. These are software
GPIO observations; physical LED and terminal behavior still require observation.
Evidence: `artifacts/countdown-boot.log`, `artifacts/countdown-hardware.log` and
`artifacts/countdown-hardware.json` (ignored local artifacts).
