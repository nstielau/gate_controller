# Base firmware 1.0.9

Successful captive setup saves now show the submitted SSID, confirm that other
networks remain, and provide a local ten-second countdown and instructions to
reconnect the phone. The server fully sends and closes the HTTP response before
waiting ten seconds and restarting. Forget operations show a removal receipt.

Native logs confirmed the prior Submit saved and restarted, but reload occurred
before request-socket cleanup. Also observed send-buffer EAGAIN (11). Replace
sendall with tracked short writes and bounded retries for EAGAIN/EWOULDBLOCK,
so retries never duplicate an unknown partially sent chunk. Send diagnostics
remain free of request bodies, credentials and arbitrary exception strings.

Validation: partial-write/EAGAIN reconstruction and close-before-reload host
tests, confirmation escaping/countdown browser tests, and USB installation.
Check the phone receipt and reconnect behavior interactively. No gate commands
are sent by these checks.
