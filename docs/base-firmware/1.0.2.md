# Base firmware 1.0.2

This base bundle adds the Adafruit ESP32-S3 Reverse TFT Feather onboarding path.
It includes local open/WPA SSID scanning, HTTPS device registration against the
Drawbridge registration function, one-time MQTT credential persistence, the
Reverse TFT boot/QR/status display adapter, and the `adafruit_miniqr` and display
text libraries required by that board. Existing XIAO GPIO, MQTT hold, OTA, and
NVM compatibility behavior remains in place.

## USB validation required

Install this base bundle over USB on an Adafruit ESP32-S3 Reverse TFT Feather,
confirm CircuitPython 10 identifies the board, run the local setup portal, verify
open/WPA networks appear without exposing saved passwords, scan the QR code, and
confirm the device persists the returned MQTT identity before entering the MQTT
loop. Run `make test` and `make test-hardware` after the intentional USB install.
